# Claim Policy

## Deterministic artifact facts

Artifacts generated by the framework are deterministic under fixed inputs:
- canonical serialized JSON,
- fixed fixture identity,
- fixed run metadata,
- fixed seeds for configured controls.

## Empirical frozen-set results

Only claims made for the configured fixture and declared experiment count as empirical.
The primary empirical gate is the frozen-set functional regression set:
`source correct / candidate wrong`.

## Statistical claims

Metric-specific envelopes are empirical and confidence-rated.
They are not universal confidence guarantees and are not quality thresholds.

## Untested hypotheses

This repository does not claim:
- universal model equivalence,
- certification,
- generalization outside the measurement fixture/domain,
- inference of production safety from this single M0 setup.
